# Unmute Labs — Project Rules

The project rules live in one place: [`.cursorrules`](.cursorrules) at the repo root.
Read it first. It covers the stack, design system, animation rules, data model,
file organization, key constraints, protocol specs, and production deploy.

To build a new Moment, follow [`.cursor/skills/new-unmute-protocol/SKILL.md`](.cursor/skills/new-unmute-protocol/SKILL.md).

For protocol actions, persistence, timers, session lifecycle, or client
synchronization, also read [`app-platform/AGENTS.md`](app-platform/AGENTS.md) and
[`app-platform/docs/workshop-reliability.md`](app-platform/docs/workshop-reliability.md).

Edit the rules in `.cursorrules`, not here, so there is only one copy.
